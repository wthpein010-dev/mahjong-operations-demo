# 雀序 · 地方棋牌运营后台

V1.6，2026-10-11。公开可分享的静态交互原型，业务名称为麻溜后台管理系统。包含多区域总览、地区负责人授权、普通推广代理、客服与微信配置、茶馆玩家查询、游戏统计与日活、房间、充值退款、负责人业绩汇总、房卡余额、历史转卡流水、奖励和操作记录。

四种身份可切换：总公司、总部客服、地区负责人、区域客服。负责人示例分别负责两个区域，一次登录汇总，支持单区或多区筛选。所有数据为虚构，修改仅保存在访问者浏览器，微信配置可刷新保留。

规则与本地V1.6需求文档一致：地区负责人包含区域客服开户职责；总部客服仅查当前服务代理经营及个人奖励；迁区联动茶馆且历史快照保留；奖励比例0–20%、次日生效；所有身份无转卡入口。当前演示不包含真实认证、后端、支付、接口同步或结算。个人密码页仅说明流程，不输入密码；生产功能细节与接口依需求文档实施。

公开地址：https://wthpein010-dev.github.io/mahjong-operations-demo/?v=1.6 。项目独立发布，不接入应用集合。公开项目不包含参考站真实账号、联系方式、游戏ID或截图，也不上传业务Word文档。
