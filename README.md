# 雀序 · 地方棋牌运营后台

公开可分享的静态交互原型。包含数据总览、区域、代理、茶馆、玩家、客服、操作记录及权限说明。

四种身份可切换：总公司、总公司客服、区域代理、区域客服。全部数据为虚构。新增账号、奖励配置和日志仅保存在访问者浏览器。区域微信修改仅在当前页面会话有效。

尚未确认的统计口径、客服数据范围、区域代理开设权限、迁移与计奖规则在权限说明页面列出。本项目不包含真实身份认证、后端、支付或结算。

## 本地预览

运行 `python -m http.server 8765` 后打开 http://localhost:8765 。也可直接打开 index.html。

GitHub Pages 从 main 分支根目录发布。
